# CityBreaks Web

Aplicação web desenvolvida em C# e ASP.NET Core (Razor pages) para o portal CityBreaks. O sistema gerencia o cadastro e a busca de propriedades, cidades e países

# Funcionalidades
* Gestão de destinos
* Gestão de propriedades
* Busca e filtros
* Soft delete (mantem historico no banco de dados)

# Tecnologias utilizadas
* Back-end: C# .NET 8.0, ASP.NET Core Razor Pages
* Banco de Dados: SQLite
* ORM: Entity Framework Core (Migrations, Fluent API, Data seeding, Eager loading)

# Como executar
1. Clone este repositório.
2. Abra no Visual Studio.
3. Abra o Console do gerenciador de pacotes e execute o `Update-Database` para gerar o banco de dados SQLite
4. Pressione `F5` para iniciar
